# wow-forever-gruppe

Ein eigenes Addon fuer **World of Warcraft: Forever** fuer unsere Gruppe,
dazu ein kleines Update-Programm fuer Windows, mit dem die Mitspieler das
Addon ohne Handarbeit aktuell halten.

Das Addon zeigt nur an und informiert. Es automatisiert keine Spielaktionen
und haelt sich an Blizzards Regeln fuer Addons.

## Ordner

| Ordner | Inhalt |
|---|---|
| `addon/GruppeDiag/` | Diagnose-Addon: prueft, welche Schnittstellen Forever bereitstellt (Schritt 1) |
| `addon/ForeverGruppe/` | das eigentliche Gruppen-Addon, Befehl `/gruppe` |
| `updater/` | Update-Programm fuer Windows (noch nicht begonnen) |
| `doku/` | Anleitungen fuer die Mitspieler |

## Fuer Mitspieler

Siehe [doku/ANLEITUNG-MITSPIELER.md](doku/ANLEITUNG-MITSPIELER.md).

## Versionen

Jede Veroeffentlichung ist ein GitHub-Release mit Versionsnummer, dem Addon
als Zip und einem Aenderungstext. Die Aenderungen stehen auch in
[CHANGELOG.md](CHANGELOG.md).
